# Kiva PDS Publication Artifacts

This directory contains machine-readable support files for the Kiva Personal
Data Store extension. The PDS contract is a Kiva platform extension layered on
top of the IEEE/ISO/IEC 39274-1-1:2025 xAPI LRS surface; it is not part of the
IEEE xAPI LRS conformance claim.

- `schemas/pds-evidence-manifest.schema.json`: JSON Schema for the PDS
  publication evidence bundle manifest generated by
  `scripts/ci/generate_pds_evidence.sh`.
- `schemas/pds-deployment-template-catalog.schema.json`: JSON Schema for
  deployment templates, legal-policy examples, and operator runbooks.
- `deployment-templates.yaml`: machine-readable public-sector and school
  deployment templates for the current PDS boundary.

Related publication artifacts:

- examples: `../../examples/pds/`
- generated OpenAPI component schemas: `../../generated/pds-openapi-schemas/`
- publication milestone mirror: `publication-milestones.yaml`
- deployment templates: `deployment-templates.yaml`
- compatibility guidance:
  `../../docs/architecture/pds-extension-compatibility.md`
- integrated milestone ledger:
  `../../docs/architecture/pds-milestones.md`

Validate the checked-in examples and generated schemas with:

```sh
python scripts/ci/validate_pds_publication.py
```

Validate only the deployment templates with:

```sh
python scripts/ci/validate_pds_deployment_templates.py
```

Generate a local evidence bundle with:

```sh
scripts/ci/generate_pds_evidence.sh --require-clean-git
```
